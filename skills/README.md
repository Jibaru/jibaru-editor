# Agent skills: personal vlog style

Skills for agents that edit with Jibaru Editor (through `jb` or `jb-mcp`, see
[docs/agents.md](../docs/agents.md)). Together they describe one house style
for personal travel and hangout vlogs shot on an action camera (4K, 29.97 fps,
wide angle). The rules and numbers were measured on finished projects the
author approved.

| Skill | Use it when |
| --- | --- |
| [vlog-structure](vlog-structure/SKILL.md) | Building the skeleton of a new vlog: intro, chapters, ending, length, deliverables |
| [cut-pacing](cut-pacing/SKILL.md) | Choosing and trimming takes |
| [transition-choice](transition-choice/SKILL.md) | Deciding whether a cut gets a transition, and which one |
| [titles-style](titles-style/SKILL.md) | Intro, chapter and reaction titles |
| [music-and-voice-mix](music-and-voice-mix/SKILL.md) | Music, voice-over and the audio mix |
| [color-look](color-look/SKILL.md) | Color, exposure, speed and small extras |
| [privacy](privacy/SKILL.md) | Someone on camera must not be recognizable |

A project's own brief always overrides these defaults. Talk to the user in
their language and show a text plan before a long render.
