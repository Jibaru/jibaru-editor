# Promo music license

`public/music/jibaru-promo-music.mp3` (and the `out/jibaru-promo-music.wav` / `.mp3`
exports) is an original composition made for the Jibaru Editor promo. It is generated
entirely by `scripts/compose-music.py`: every sound is synthesized by that code
(oscillators, filtered noise and a generated reverb impulse). It uses no samples,
loops, presets or third-party recordings. The script is deterministic (fixed seed), so
`npm run music` rebuilds the same track.

- Title: Jibaru Promo
- Tempo / key: 120 BPM, F minor
- Length: 30 s, 48 kHz stereo
